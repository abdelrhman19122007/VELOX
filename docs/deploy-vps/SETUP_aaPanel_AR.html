تشغيل VELOX على السيرفر

الورقة دي لصاحب السيرفر 169.58.19.62. الوقت المتوقع: حوالي ١٥ دقيقة من لوحة التحكم (aaPanel)، ومش محتاج تدّي حد أي دخول.

VELOX تطبيق توصيل (مشروع تخرج DEPI). عبارة عن برنامج Java واحد (velox.jar) بيشتغل على بورت 8080 جوه السيرفر، وnginx بيوصّل الزوار ليه. قاعدة البيانات مش على السيرفر ده (هي على Supabase)، فمفيش داتابيز تتسطّب.
الاستهلاك: حوالي 300 لـ 600 ميجا رام، ومعالج قليل جداً.

الحاجات اللي هتوصلك

الملفإيه ده
velox.jarالبرنامج نفسه (حوالي 29 ميجا)
velox.envالإعدادات: بيانات قاعدة البيانات ومفتاح الأمان. نبيه هيبعتهولك لوحده، ودي ملف سري
ملفات الموقعنبيه هيرفعها بنفسه بحساب الـ FTP nabeeh_abosalem (فولدرين web وapp). مش مطلوب منك حاجة فيها

الخطوات

1
شغّل الموقع. من Website، الموقع المربوط بحساب الـ FTP nabeeh_abosalem حالته دلوقتي Stopped. دوس عليها عشان تبقى Running.
وابعت لنبيه مسار فولدر الموقع (Root directory)، زي /www/wwwroot/169.58.19.62.
2
اعمل فولدرين من Files: 
/www/velox                  ← هنا velox.jar و velox.env
/www/velox-data/uploads     ← الصور اللي المطاعم بترفعها
ارفع velox.jar وvelox.env جوه /www/velox.
3
كمّل ملف الإعدادات. افتح /www/velox/velox.env وغيّر الكلمة <SITE> في السطرين دول للمسار اللي في الخطوة 1: 
velox.web.dir=<SITE>/web
velox.app.dir=<SITE>/app
وبعدين خلّي صلاحيات الملف 600 (Permission)، عشان محدش غير البرنامج يقراه.
4
سطّب Java 17. من Website ← Java Project (أو App Store)، سطّب JDK 17 لو مش موجود.
5
ضيف المشروع. Website ← Java Project ← Add Java project:
Project typeSpring Boot / Jar
Project jar/www/velox/velox.jar
JDK17
Port8080 — من غير ما تفتحه في الـ Firewall
Run userwww
Startup command / Project commandالسطر اللي تحت بالظبط
java -Xmx512m -jar /www/velox/velox.jar --spring.config.import=file:/www/velox/velox.env[.properties]
لو اللوحة طلبت مكان Domain، سيبه فاضي أو حط الدومين، لأن الخطوة 6 هي اللي بتوصّل الموقع.
دوس Start، واستنى حوالي 30 ثانية.
6
وصّل الموقع بالبرنامج (Reverse Proxy). من الموقع بتاع الخطوة 1 ← Reverse proxy ← Add:
Proxy namevelox
Proxy dir/
Target URLhttp://127.0.0.1:8080
Send domain$host
بعد ما تحفظ، افتح Config file بتاع الـ proxy وضيف السطور دي جوه location /. دي عشان الطلبات الجديدة توصل للمطعم فوراً (Live updates): 
proxy_http_version 1.1;
proxy_set_header Connection "";
proxy_buffering off;
proxy_cache off;
proxy_read_timeout 3600s;
proxy_set_header X-Forwarded-Proto $scheme;
proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
client_max_body_size 5m;
7
HTTPS (لو فيه دومين). اربط الدومين بالموقع، ومن SSL ← Let's Encrypt اعمل شهادة، وفعّل Force HTTPS. وبعدها غيّر السطر ده في velox.env واعمل Restart للمشروع: 
VELOX_CORS=https://الدومين

اتأكد إنه شغال

افتح من المتصفح:
• http://169.58.19.62/api/zones ← لازم تظهر بيانات بالشكل ده [{"code":...
• http://169.58.19.62/ ← هيظهر موقع VELOX، بعد ما نبيه يرفع الملفات
وابعت لنبيه "اشتغل" عشان يعمل الاختبار الكامل.

التحديث بعد كده

نبيه هيبعت velox.jar جديد. حطه مكان القديم في /www/velox، واعمل Restart للمشروع، وخلاص. ملفات الموقع نبيه بيحدّثها بنفسه بالـ FTP.

الأمان

• متفتحش بورت 8080 في الـ Firewall. الزوار بيدخلوا من 80/443 بس، وnginx هو اللي بيوصّلهم.
• velox.env فيه باسورد قاعدة البيانات، فخليه 600 ومتبعتهوش لحد.
• البرنامج بيشتغل كيوزر www مش root، ومش بيكتب غير في /www/velox-data/uploads.
• صفحات الـ API docs (Swagger) مقفولة.

أسماء القوائم ممكن تختلف شوية حسب نسخة aaPanel. لو أي خطوة مش واضحة، كلّم نبيه.
