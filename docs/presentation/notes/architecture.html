Presenter: Nabeeh. Every client talks to one REST API over HTTPS and JSON; the restaurant and customer screens also keep one live connection (Server-Sent Events). Inside the API each request goes Controller → Service (rules and role checks) → Repository (SQL through JDBC with parameters). The server, database and website run together in Docker with one double-click.
