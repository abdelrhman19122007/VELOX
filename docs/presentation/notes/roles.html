The VELOX ecosystem

Four connected roles

01

Customer

Browses menus, orders, applies codes, pays and tracks, and can ask for “Get Me Anything”

02

Restaurant

Hears new orders, accepts or rejects, marks ready, manages menu and prices

03

Courier

Goes online, takes an order, picks it up and delivers, sharing live location

04

Administrator

Runs stores, zones, fees, users, codes and complaints, and watches daily numbers

One app for the first three roles. The page you see depends on the account you sign in with.

VELOX

Presenter: Fady. Explain that customer, restaurant and courier use the same Flutter app; the server decides what each account can see and do (role-based access). The admin uses a web dashboard.
