# Usability test plan

**Owner:** Hoda (@hodayasser511-stack) — UI/UX

## Goal
Check that people in Samannoud can order, pay and follow an order without help, on their own phones.

## Participants (5)
- 2 regular smartphone users (18–30)
- 2 occasional users (30–50)
- 1 older user (50+)
At least one from a village outside the city.

## Tasks (think aloud, no help)
| # | Task | Success when |
|---|---|---|
| T1 | Create an account | signed in < 2 min |
| T2 | Choose your village and find a koshary restaurant | store opened |
| T3 | Order 2 items, one with a note, pay cash with change for 200 | order placed |
| T4 | Use the code VELOX10 | discount shown before placing |
| T5 | Order with Fawry and find the reference number | reference read aloud |
| T6 | Follow the order and call the driver | map seen, call button found |
| T7 | Ask for something not in any store ("bring me anything") | errand placed |
| T8 | Rate the order and report a problem | both sent |

## Measure
Task success, time, errors, and a 1–5 ease score per task. Note every place someone hesitates.
